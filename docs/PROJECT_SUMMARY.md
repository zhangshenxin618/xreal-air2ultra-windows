# 项目总结

## 目标

将开源的 macOS Air 2 Ultra 双目摄像头项目适配到 Windows，提供可使用、可复查的视觉数据采集与处理工具。

## 已完成

实现定向原始采集、分块图像还原、异常帧恢复、双目配对、镜像和方向校正、条纹清理。通过物理遮挡确认左右镜头。提供普通模式眼镜全屏、截图、MP4 录像、原始数据录制和离线视频导出，并补充麦克风录制与音轨合成功能。

开发期间解决了误开内置摄像头、Windows 自动颜色转换、启动状态字段变化、左右交替导致倒置闪烁及按键焦点等问题。实际采集验证曾达到连续 300 帧、150 对双目画面。声音合成通过自动测试，真实麦克风录音尚待本机验证。

## 与原项目的关系

沿用上游图像重排原理和相关算法思路，新增 Windows 采集与交互、当前眼镜遥测适配、原始录制格式、离线导出及音频模块。保留上游 MIT 许可和来源说明，不将上游算法归为本地原创。

## 当前边界与下一步

当前成果是 Windows 摄像头预览与采集原型，尚非完整的 AR 或立体透视系统。下一步优先验证真实音画同步及眼镜 SBS 分眼显示，再开展相机标定、畸变校正和深度实验。SLAM 与 IMU 融合未实现。
